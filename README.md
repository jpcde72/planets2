# planets2

Interactive Planet Builder & Explorer:
- procedural star system generator
- 3D visualization with orbit controls
- planet explorer cards
- atlas-style map inspection
- field reports for fauna, flora, biomes, climate zones, and geographical features
- extra interactions: climate slice, expedition planner, and seasonal time-lapse

## Run
Open `index.html` in a modern browser (internet access required for the Three.js CDN imports).
